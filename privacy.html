Privacy Policy

Draya_youtube — last updated 22 September 2026.

Who this covers

Draya_youtube is a personal command-line tool used by a single person to upload their own videos to their own YouTube channel. It has no other users, no sign-up, and no public interface.

What data the application accesses

  • The Google Account that signs in, solely to act on that account's own YouTube channel.
  • YouTube channel and video data belonging to that account: video titles, descriptions, privacy status and upload results.

The application does not access contacts, e-mail, files, location, or any data belonging to anyone else.

How the data is used

Only to upload a video the owner has chosen, set its title, description and privacy status, and confirm that the upload succeeded. The data is not analysed, profiled, sold, or shared with third parties, and it is not used to train machine-learning models.

Where the data is stored

The OAuth access and refresh tokens are stored in a file on the owner's own computer, readable only by the owner's system account. No copy is kept on any server operated by the application. Nothing is stored in a database or sent to any analytics service.

Data retention and deletion

Tokens remain on the owner's computer until they are deleted or revoked. Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately stops the application from using the account.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

AI-generated content

Draya is an AI-generated character. Videos published through this tool are labelled as AI-generated in their description and through YouTube's synthetic-media flag.
