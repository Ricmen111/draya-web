Privacy Policy

Draya_tiktok — last updated 25 September 2026.

Who this covers

Draya_tiktok is a personal command-line tool used by a single person to send their own videos to their own TikTok account (@draya.sin). It has no other users, no sign-up, and no public interface.

What data the application accesses

  • Basic profile information of the TikTok account that authorises it (open ID, display name, avatar), solely to confirm the right account is connected.
  • The status of videos the owner uploads through the tool (upload and processing results).

The application does not access followers, messages, contacts, location, or any data belonging to anyone else.

How the data is used

Only to upload a video the owner has chosen to their own TikTok account and confirm that the upload succeeded. The data is not analysed, profiled, sold, or shared with third parties, and it is not used to train machine-learning models.

Where the data is stored

The OAuth access and refresh tokens are stored in a file on the owner's own computer, readable only by the owner's system account. No copy is kept on any server operated by the application and nothing is sent to any analytics service.

Data retention and deletion

Tokens remain on the owner's computer until they are deleted or revoked. Access can be withdrawn at any time in the TikTok app under Settings and privacy → Security → Manage app permissions, which immediately stops the application from using the account.

AI-generated content

Draya is an AI-generated character. Videos published through this tool are labelled as AI-generated using TikTok's AI-generated content label.
